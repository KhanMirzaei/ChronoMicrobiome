ChronoµBiome

Human microbiome dynamics and responses to exposures.

Follow bacterial and phage communities through time. Explore changes associated with medications, antibiotics, and diet, and describe persistence and return toward personal baseline.

Explore the synthetic demo →View source on GitHub
Research preview. The semaglutide example uses entirely simulated data. It is not evidence about Ozempic or any medication's effects. The tool has not yet been validated on a real cohort.

Exposure-associated change

Compare changes across study phases using repeated-measures models, explicit covariates, confidence intervals, and multiple-testing correction.

Persistence and recovery

Track observed detection and community distance from each participant's baseline, with explicit handling of insufficient follow-up.

Phage–host trajectories

Explore supplied host links using within-person residual associations and evidence-confidence filters.

Start with your own study

Supply processed bacterial abundance tables, optional phage abundances and host links, and participant metadata. Raw sequencing processing is outside the scope of this release.

git clone https://github.com/KhanMirzaei/ChronoMicrobiome.git
cd ChronoMicrobiome
Rscript -e 'install.packages(c("nlme", "ggplot2", "yaml", "jsonlite"))'
Rscript bin/chronomicrobiome demo --output my-study --run

The package and command use the ASCII spelling chronomicrobiome. Quarto is optional; reports also work with the built-in offline renderer.

Transparent by design

Results include model diagnostics, input fingerprints, software versions, analysis settings, and downloadable tables. Local validation passed 50 automated assertions and R CMD check.

Associations do not establish causal drug effects or phage infection. Confidence intervals and recovery thresholds need study-specific interpretation. See the methods and validation notes before using results in research.
